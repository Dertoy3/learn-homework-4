# Задание 8. Журнал ухода за растениями

1. Перенеси работающий класс Plant из задания 6 в models.py.
2. Реализуй сохранение списка растений и загрузку объектов из JSON в storage.py.
3. app.py уже содержит сценарий: загрузить данные, добавить первое растение при пустом списке, увеличить счётчик первого растения, сохранить и показать состояния.
4. Для отсутствующего файла load_plants возвращает []. Повреждённый JSON должен вызвать JSONDecodeError.
5. Формат JSON: список словарей с ключами name и water_count. В этом задании структура корректного JSON считается подходящей, отдельная проверка схемы не нужна.
6. После загрузки каждый элемент результата должен быть экземпляром Plant, а не словарём.
7. Запусти тесты из корня: python -m unittest discover -s tests -v
8. Добавь тест на отрицательный счётчик и тест независимости двух растений.

В save_plants родительская папка уже существует.
Для пустого списка записывай [].
После первого запуска app ожидается water_count=1. Повторный запуск даёт 2.
Для нового журнала можно выбрать другой путь вместо удаления чужих данных.
