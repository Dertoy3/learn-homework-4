# Python: домашняя работа №4

Модули и пакеты, зависимости, файлы и JSON, исключения, отладка, классы и простые тесты.

Нужен Python 3.10 или новее. Обязательные задания используют только стандартную библиотеку.
Примеры в презентации посвящены музыке и другим темам. Здесь задачи про преобразования температуры, списки покупок и растения.

## Порядок работы

1. Клонируй репозиторий и открой его корневую папку.
2. Выполняй задания по порядку. Условия находятся в описаниях функций и README.
3. Замени pass кодом. В main уже есть данные и вызовы для запуска.
4. Сравни результаты с условиями. None в заготовке обычно означает, что return пока отсутствует.
5. Тесты в заданиях 7 и 8 запускаются отдельно. До реализации кода проверки могут завершаться с FAIL или ERROR.
6. Сохрани изменения через commit и push.

| № | Тема | Запуск из корня |
|---|---|---|
| 1 | Свой модуль и пакет | python task1_modules/main.py |
| 2 | Окружение и зависимости | См. task2_environment/README.md |
| 3 | Текстовые файлы | python task3_files.py |
| 4 | JSON | python task4_json.py |
| 5 | Исключения и отладка | python task5_errors.py |
| 6 | Класс Plant | python task6_classes/main.py |
| 7 | Свои тесты | python -m unittest discover -s task7_tests -v |
| 8 | Мини-проект | python -m plantbook.app |

Для задания 8: python -m unittest discover -s tests -v

## Требования к решениям

- Не перехватывай все исключения одним except без объяснения.
- Сохраняй текст с encoding="utf-8", файлы закрывай через with.
- Не меняй исходные коллекции без указания в условии.
- Код при импорте не должен запрашивать ввод или записывать пользовательские данные.
- Не добавляй .venv, __pycache__ и work_results в Git.
- Тест проверяет обещанное поведение и использует собственные данные.

Итоговый проект чуть сложнее отдельных упражнений: сначала заверши задания 1–7.
