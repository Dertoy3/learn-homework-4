# Домашняя работа №4: классы и JSON

Собери простую викторину из нескольких Python-модулей.
Все части работают в одном процессе. Общий main.py связывает их обычными импортами.
Нужно реализовать классы и чтение/запись JSON.

## Структура

    main.py
    quiz_app/
        __init__.py
        question.py       # Один вопрос
        quiz.py           # Загрузка вопросов и проверка ответов
        storage.py        # История результатов в JSON
    data/
        questions.json
        answer_key.json
        demo_answers.json

## Что уже готово

Данные и main.py с вызовами. Все пути считаются от папки проекта.
В заготовках стоят NotImplementedError с названием метода.
Пока метод не реализован, main выводит понятное сообщение.

## Задание 1. Класс Question

Файл quiz_app/question.py.

1. В __init__(question_id, text, options) сохрани self.id, self.text и self.options.
2. options — словарь букв и вариантов. Сохрани его через dict(options).
3. as_dict() возвращает словарь с ключами id, text и options.
4. В as_dict возвращай отдельную копию options.

Например: Question("q1", "Тип данных?", {"A": "list", "B": "dict"}).

## Задание 2. Класс Quiz

Файл quiz_app/quiz.py.

1. __init__ уже сохраняет пути к файлам.
2. load_questions() читает questions.json через with и encoding="utf-8".
3. Для каждого словаря создаёт Question и возвращает список этих объектов.
4. check_answers(answers) читает answer_key.json.
5. answers — словарь вида {"q1": "B", "q2": "A"}.
6. Сравни ответы ученика с правильными. Пропущенный ответ считается неправильным.
7. Верни {"correct": число_верных, "total": число_вопросов, "percent": процент}.
8. total равен размеру ключа ответов. Процент округли до одного знака.
   Для пустого ключа верни correct=0, total=0, percent=0.0.

В этом упражнении считаем, что входные типы и структура JSON корректны.
Сравнение букв учитывает регистр. Лишние id в answers не учитывай.
Переданный словарь answers изменять не нужно.

## Задание 3. Класс ResultStorage

Файл quiz_app/storage.py.

1. __init__ уже сохраняет путь.
2. load() читает JSON со списком результатов.
3. Если файла пока нет, верни []. Обрабатывай только FileNotFoundError.
4. save(result) получает словарь с correct, total и percent.
5. Прочитай старый список через load(), добавь копию нового результата.
6. Создай родительскую папку, если её нет.
7. Запиши весь список через json.dump: UTF-8, ensure_ascii=False, indent=2.
8. Верни None.

Повреждённый JSON не подменяй пустым списком.
Каждый запуск должен добавлять запись, сохраняя предыдущие.

## Запуск

Нужен Python 3.10 или новее. Сторонние пакеты не нужны.
Запускай из корневой папки:

    python main.py

Ожидаемый результат после реализации:

    Верно: 2 из 2
    Процент: 100.0
    Результатов в истории: 1

На следующем запуске история содержит 2 записи.
Новый файл автоматически создаётся в work_results/results.json.
Правильные ответы в demo_answers.json нужны для демонстрации запуска.

## Самостоятельная проверка

- Запусти main.py с исходными демонстрационными ответами.
- Измени один ответ: ожидаются 1 из 2 и 50.0.
- Замени ответы на {}: ожидаются 0 из 2 и 0.0.
- Верни исходный demo_answers.json перед сдачей.
- Посмотри JSON истории: старые результаты должны остаться.
- Объясни, какой класс за что отвечает и как main связывает их.

Тестовые файлы, HTTP, серверы и запуск отдельных процессов здесь не нужны.
Сделай commit и push с реализацией методов.
